# dsh-tab-title

Браузерный плагин для [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness), который сохраняет предсказуемый заголовок вкладки веб-интерфейса и показывает ненавязчивые уведомления в фоновой вкладке.

[English version](README.md)

## Что делает плагин

- Закрепляет обычный заголовок вкладки: `DeepSeek Harness`, даже если интерфейс заменяет его названием текущего чата.
- Показывает `✓ DeepSeek Harness`, когда агент завершил ход, пока вкладка находится в фоне.
- Показывает `❓ DeepSeek Harness`, когда агент ждёт ответа, проверки плана или одобрения, пока вкладка находится в фоне.
- Сбрасывает уведомление при возвращении на вкладку или запуске нового хода.
- Поддерживает API pending interactions из alpha1 и единый API session status из alpha2.

Плагин работает только в браузере. Он не добавляет серверной логики, не собирает данные и не меняет содержимое диалогов.

## Установка

Установите плагин напрямую из GitHub:

```sh
dsh plugin add github:DobroGnom/dsh-tab-title
```

Затем включите **dsh-tab-title** в разделе **Настройки → Плагины** и перезагрузите веб-интерфейс, если он уже открыт.

Для локальной копии:

```sh
dsh plugin add /absolute/path/to/dsh-tab-title
```

## Разработка

```sh
pnpm install
pnpm test
pnpm build
```

Сборка создаёт `lib/client.js` и `lib/index.js` — артефакты плагина, которые загружает DeepSeek Harness.
